## Findings and resolutions

First pass verdict: **REQUEST CHANGES** — 17 findings, all resolved:

1. `[INVARIANT]` Never-imported `ArrowBatch.close()` leaked the Rust-side
   release (arrow-java's `close()` never fires the release callback).
   **Resolved**: explicit `release()` on the un-imported path + tests
   (unimported close, out-of-range batch error path).
2. `[INVARIANT]` Handle use-after-free race — accessors read the handle under
   lock but called native outside it in `QueryResult`, `QueryStream`,
   `ExecuteResult`, `Writer`, `LaminarConfig`. **Resolved**: lock held across
   every native call; `QueryResult`'s "thread-safe for reads" Javadoc claim
   removed (single-owner, matching docs/threading.md).
3. `[INVARIANT]` Error paths in `batch()`/`pull()` leaked the FFI containers.
   **Resolved**: catch-close-rethrow in both.
4. `[DEAD]` `Native.isClosed` had no caller. **Resolved**: deleted both
   sides; Java checks its own nulled handle (no JNI crossing).
5. `[DEAD]` `writerFree` wired to nothing. **Resolved**: Cleaner backstop
   with an atomic claim — exactly one freer between `close()` and the
   cleaner; `close()` never joins the cleaner thread (the naive
   `cleanable.clean()` deadlocked against a concurrent backstop; found by
   test hang, root-caused via thread dump).
6. `[DEAD]`/`[TESTS]` Nine public members unexercised. **Resolved**:
   `SurfaceCoverageTest` covers them (ArrowBatch insert/write paths, result
   and stream schemas, kinds, double-close everywhere, timestamp read-back,
   schema/field accessors); `shutdownDefaultAllocator` documents why the
   in-suite cannot exercise it (would poison the shared allocator) — plan
   claim amended accordingly.
7. `[DOCS]` Review record missing. **Resolved**: this file.
8. `[STRUCTURE]` Version drift pom vs Cargo. **Resolved**: both
   `0.30.0-alpha`; semver test accepts pre-release suffixes.
9. `[STRUCTURE]` Release workflow's verify step rebuilt the jar without
   natives. **Resolved**: bundling stays active through the suite run.
10. `[DOCS]` Duplicated/orphaned `Schema.fields()` Javadoc. **Resolved**.
11. `[DOCS]` Garbled exception summary. **Resolved**.
12. `[DOCS]` Comment referenced nonexistent Rust `type_name`. **Resolved**:

13. `[SLOP]` pom comment contradicted the add-opens requirement.
    **Resolved**.
14. `[SLOP]`/`[TESTS]` Dead defensive check and unreachable-at-pin DATE
